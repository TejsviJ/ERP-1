# BD Client Desk

Duplicate of a work done for a manufacturing company requiring ERP software. Demonstrating a browser-based ERP/client desk interface and a Supabase-backed data layer. 


## Project overview

- `index.html` — application interface.
- `data.js` — Supabase client and data access layer.
- `config.example.js` — placeholder template for local Supabase configuration.
- `config.js` — local configuration file; ignored by Git and not included in this repository.
